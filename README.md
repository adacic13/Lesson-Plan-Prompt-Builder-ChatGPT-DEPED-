# Lesson-Plan-Prompt-Builder-ChatGPT-DEPED-
A customizable, browser-based Lesson Plan Prompt Builder designed to help teachers create detailed, practical, and classroom-ready lesson plan prompts using ChatGPT. Supports different educational levels, subjects, curriculum frameworks, teaching strategies, learner needs, assessment methods, and classroom resources with no installation required.


# Teacher Lesson Plan Prompt Builder

The **Teacher Lesson Plan Prompt Builder** is a simple, customizable web tool that helps teachers generate structured prompts for creating lesson plans with ChatGPT.

Instead of writing lengthy prompts manually, teachers can enter their lesson details, select relevant teaching strategies, specify learner needs, and define classroom resources. The tool combines these selections into a detailed prompt that can be copied and used directly in ChatGPT.

### Features

- Support for different educational levels, from early childhood to higher education and technical-vocational training.
- Customizable subject, lesson topic, learning objectives, and curriculum framework.
- Dynamic Term and Quarter selection based on educational level.
- Teaching strategies and differentiated instruction options.
- Learner profiles, classroom resources, and technology availability.
- Assessment methods and additional lesson plan requirements.
- Automatic prompt generation for ChatGPT.
- Simple, responsive interface that runs directly in a web browser.

### Technologies

- HTML
- CSS
- JavaScript

### How to Use

1. Download or clone this repository.
2. Open the HTML file in your web browser.
3. Fill in the lesson details and select your preferred options.
4. Generate and copy the lesson plan prompt.
5. Paste the prompt into ChatGPT and provide any required lesson plan template or supporting materials.

### Purpose

This project aims to make lesson planning more convenient and organized by helping teachers prepare clear, detailed prompts tailored to their teaching context. Teachers should review and adapt generated lesson plans to their learners, school requirements, and applicable curriculum guidelines.
